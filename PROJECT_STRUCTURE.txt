run_parallel.sh
└─ 自动并行运行：
   ├─ run_methods_part1.sh (2 方法 × 81 = 162 个实验)
   ├─ run_methods_part2.sh (2 方法 × 81 = 162 个实验)
   └─ run_methods_part3.sh (2 方法 × 81 = 162 个实验)

每个脚本循环：6 种方法 → 3 个种子 → 3 个 LLM lambdas → 3 个 Mixup lambdas → 3 个学习率
