⚙️ 脚本工作原理：

run_parallel.sh 的执行流程：
│
├─ 启动 run_methods_part1.sh 为后台进程 1
├─ 启动 run_methods_part2.sh 为后台进程 2
├─ 启动 run_methods_part3.sh 为后台进程 3
│
├─ 等待所有 3 个进程完成
│  │
│  ├─ Part 1: 处理 方法 1-2（162 个实验）
│  ├─ Part 2: 处理 方法 3-4（162 个实验）
│  └─ Part 3: 处理 方法 5-6（162 个实验）
│
└─ 所有进程完成后打印最终报告

每个 run_methods_partX.sh 的执行流程：

对于每个方法组合 (例如 mlp:query_attn)：
  对于每个种子 (1, 2, 3)：
    对于每个 lambda_llm (0.01, 0.05, 0.1)：
      对于每个 lambda_mixup (0.05, 0.1, 0.2)：
        对于每个学习率 (0.0005, 0.001, 0.002)：
          1. 复制基础配置文件 → configs/temp_grid.yaml
          2. 使用 Python 更新超参数
          3. 运行: python train_modular.py --config configs/temp_grid.yaml
          4. 删除临时配置文件
          → 输出自动保存到 my_caches/...
